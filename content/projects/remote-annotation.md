**Members:** [Jai Sai Naga Venkat Guttikonda]({{< relref "/authors/jai-sai-naga-venkat-guttikonda" >}}) · [Regis Kopper]({{< relref "/authors/regis-kopper" >}})

MMW explores techniques for precise remote annotation in virtual reality. It enables users to draw, trace, and annotate content on large virtual surfaces by interacting with a smaller, more accessible proxy representation of the workspace.

{{< project_figure src="media/projects/mmw-remote-annotation/figure-1.jpeg" alt="A user performing a remote annotation task in virtual reality using the MMW interface." >}}
**Figure 1.** A user performing a remote annotation task in virtual reality using the MMW interface.
{{< /project_figure >}}

The research investigates different aspects of the MMW technique to understand how they influence annotation performance and user experience. By systematically exploring its interaction methods and design choices, we aim to identify approaches that improve precision while balancing physical effort and ease of use. These findings help guide the development and refinement of MMW for more effective remote interaction in virtual environments.
