**Members:** [Jai Sai Naga Venkat Guttikonda]({{< relref "/authors/jai-sai-naga-venkat-guttikonda" >}}) · [Regis Kopper]({{< relref "/authors/regis-kopper" >}})

MMW explores techniques for precise remote annotation in virtual reality. It enables users to draw, trace, and annotate content on large virtual surfaces by interacting with a smaller, more accessible proxy representation of the workspace.

{{< project_figure src="media/projects/mmw-remote-annotation/figure-1.jpeg" alt="A user performing a remote annotation task in virtual reality using the MMW interface." hover="true" >}}
**Figure 1.** A user performing a remote annotation task in virtual reality using the MMW interface.
{{< /project_figure >}}

The research examines how MMW's interaction methods and design choices affect annotation precision, physical effort, and ease of use. It aims to inform remote interaction techniques that support accurate annotation and a comfortable user experience.
