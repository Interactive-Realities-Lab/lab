Continuous Authentication in Extended Reality is a research project investigating methods for continuously verifying user identity in immersive environments without interrupting the user experience.

Traditional authentication methods, such as passwords and one-time verification, typically authenticate users only at the beginning of a session. However, extended reality (XR) environments require continuous security mechanisms to ensure that the authenticated user remains the legitimate user throughout the session.

This project explores the use of physical behavioral patterns and motion data collected from XR headsets and external wearable sensors to support continuous authentication.

The system is being developed using Unity and Meta Quest hardware, integrating external inertial measurement unit (IMU) sensors to collect and analyze motion data during VR interactions.

The project aims to develop an authentication framework that operates continuously, minimizes interruptions to users, and supports secure immersive experiences.
