# Interactive Realities Laboratory

Website source for the Interactive Realities Laboratory (IRLab), directed by Dr. Regis Kopper at Iowa State University.

IRLab studies extended reality (XR), 3D interaction, immersive simulation and training, and applied XR systems for public safety and healthcare.

## Local preview

On Windows, open PowerShell in this folder and run `./preview.ps1`. The script downloads the Hugo version used by the project and starts a local preview.

## Content and assets

- Pages and project records are in `content/`.
- People profiles use `data/authors/` and `content/authors/`.
- Site identity and Hugo settings are in `config/_default/`.
- Images and logos are in `assets/media/` and `static/`.

The site publishes English content only.
