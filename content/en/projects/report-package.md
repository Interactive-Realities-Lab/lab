The `report` package is part of the [easystats](https://easystats.github.io/easystats/) ecosystem for accessible and reproducible statistical analysis in R. It translates model outputs into structured summaries that researchers can inspect, communicate, and integrate into reproducible workflows.

This project combines ongoing software maintenance with manuscript development. It supports the lab’s commitment to methodological tools that make good statistical practice easier to apply in everyday research.

## Current pipeline

- Maintaining the package and responding to open issues
- Revisiting the existing manuscript draft
- Clarifying the package’s role within the [easystats](https://easystats.github.io/easystats/) ecosystem
