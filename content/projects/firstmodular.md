FirstModulAR is a research platform for designing, prototyping, and evaluating modular augmented-reality interfaces for first responders. The project investigates how reusable AR interface modules can support situational awareness and decision-making across public-safety scenarios while minimizing cognitive overload and fitting existing operational practices.

The platform includes example scenarios for traffic stops, fire search and rescue, and emergency medical services. It is designed as a modular, cross-platform Unity framework for research and prototyping.

The project is supported by the NIST Public Safety Communications Research program ($1,799,040; 2022–2027; award 70NANB22H096). Project collaborators include Iowa State University, Augusta University, NextGen Interactions, and first responders. See the [FirstModulAR project site](https://fmar.nextgeninteractions.com/) for more information.
