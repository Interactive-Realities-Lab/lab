## Submit in your browser

1. **Fork or sync.** Sign in and open [Interactive-Realities-Lab/lab](https://github.com/Interactive-Realities-Lab/lab). First time only: **Fork → Create a new fork** if shown, choose your username as **Owner**, then **Create fork**. Before later requests, open your fork and click **Sync fork → Update branch**.
2. **Open and edit.** In **YOUR-USERNAME/lab**, select **main**, then open **submissions → members → your folder**. Open **profile.md** or **updates.md**, click the pencil (**Edit this file**), and replace prompts with your English information.
3. **Commit.** Click **Commit changes…**, enter a short description, choose **Commit directly to the main branch**, then click **Commit changes**. Repeat for the other file if needed.
4. **Upload attachments (optional).** In your folder, click **Add file → Upload files**, select your files, then **Commit changes** to **main**. Keep the real extension, such as **portrait.jpg**. Edit the relevant Markdown file to include the uploaded filename and commit again. Include a photo for your first profile; replacements are optional.
5. **Open a pull request.** From your fork, click **Contribute → Open pull request**. Check **base repository: Interactive-Realities-Lab/lab**, **base: main**, **head repository: YOUR-USERNAME/lab**, **compare: main**. Review **Files changed**. Click **Create pull request** to open the form if needed, enter a title and description, then **Create pull request**. You are finished when you see **Open #…**; wait for review.

If a previous request is still open, edit and commit on its source branch; it updates automatically. Keep unsynced work if sync reports conflicts. Submit only material intended for the public website.
